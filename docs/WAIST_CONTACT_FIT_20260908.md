# 未绑定腰带：接触面与前侧外凸分开约束

当前有效候选为 `workspace/local_generation/actor_offline_gate_20260908/waist_contact_v5`。它使用同一 50k 素体与已有本地 Hunyuan 腰带腰包，没有重新生图、重新生成人体、人工修改素体或绑定骨骼，也没有注册到 Studio 或资产库。

## 方法改变

旧版使用整个配件包围盒缩放，再只向外避让；这个过程无法把原本过松的腰带向内贴合，还把腰包与腰带当作相同的空间约束。

新增显式选项 `--radial-contact-fit`：从腰线 360 个方向的射线测得腰带内圈与人体半径，得到可向内/向外移动的角向位移场。各方向的配件顶点共享位移，不将扣件/腰包压扁成身体表面，也不改变面索引。位移绝对值限制为身高的 6%；如果腰线不能测到完整人体/腰带圈，拒绝执行。

接触和空间分别检查：

- 腰线内圈间隙在 `0.003–0.015H`。
- 前向区域（径向方向 Y < -0.25，Blender 坐标）相对人体外凸不超过 `0.065H`；其他区域不超过 `0.03H`。
- 原左右、上下、后侧边界继续保留；前侧采用上述人体相对限制。
- 表面三角形相交检查之外，双向各抽样最多 1024 顶点，用三个方向射线奇偶检查包含关系。不同方向不一致就拒绝，不以多数票强行通过。

这是**几何接触/前侧外凸分类，不是已经语义分割出独立腰包**。预算是本轮实验限制，不代表通用风格或所有配件的标准。原 AABB 检查在当前候选仍为 false，报告保留 `legacy_envelope_contained=false`；新候选通过的是显式 `waist_contact_front_relief_v1` 合同，不是修改旧失败记录。

## 结果与限制

宽/深系数 `0.9/0.9` 的接触候选仍超预算，未放行。改为 `0.85/0.85` 后，腰线高度保持不变：

- 接触间距 `0.005743–0.006255H`；最大外凸 `0.064484H`；越界顶点 0。
- 表面相交 0；双向各 1024 样本均无内部点、无不确定票。
- 输入/输出在内存按完全相同坐标合并法线接缝后，均为 256496 面、128258 几何顶点、10 个封闭组件、Euler=10、面朝向一致。只做审计，不修改导出文件。
- GLB 因平面法线拆分为 766945 渲染顶点，尚未优化配件渲染预算；这不是最终低模，也未做 3060 实机验收。
- 状态为 `pass_static_tpose`，仍需要人工外观审核。全网格自交、未抽样位置、动态间隙和蒙皮不在通过范围内。

中间 v3/v4 的包含检查存在数值问题：带膨胀 epsilon 的 BVH 适合保守相交检查，但会制造射线重复计数；最终包含检查单独使用零 epsilon BVH 和受限射线步进。v5 是完成此修正后的记录。不能只拿 v2 未包含双向检查的 pass 作为最终状态。

新增 5 项 Blender 后台测试覆盖闭合圈贴合、面索引不变、拒绝开口圈、拒绝过大位移、内部/外部点和密集圈包含检查；原离线素体 8 项测试也通过。测试夹具仅用于验证算法，不是用规则构造生产配件。
