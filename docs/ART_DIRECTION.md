# AssetsStudio 美术方向基准

- 状态：`accepted_direction`
- 生效日期：2026-08-09
- 视觉基准载体：当前 Actor V1；新规范图待 F001 建立后生成并人工确认
- 目标项目：BomboAdventure

## 核心方向

角色采用 **Q 版日漫 JRPG** 风格。气质参考《零之使魔》的轻幻想、明快和角色亲和力，以及《英雄传说：闪之轨迹》的清晰服装层次、学院/JRPG 角色可读性和较干净的材质表达。

这些作品用于描述风格坐标，不用于复制具体角色、服装、纹章、构图或受版权保护的独特设计。

## 当前结构基准

- 身体比例、头身关系、手脚体积和骨骼动画以 `milestones/body/chibi_actor_mixamo_walk_v1.blend` 为准。
- 当前 Actor 是 3D 结构真相，但材质、发型、服饰细节和最终像素表现仍可继续向本美术方向靠拢。
- 第一阶段男女角色共享同一人形 Actor 合同，主要通过发型、五官、耳朵、服装、配色和配件形成差异；不提前引入未经验证的男女身体拓扑分叉。
- 耳朵是可变化标准件，不属于不可替换的身体拓扑。Actor V2 基体只提供左右耳根定位点与贴合边界；人类耳、精灵耳及后续幻想种族耳以独立 `EarPair` 槽装配。
- 发型强调成组的大块发束和清晰外轮廓，避免高频写实发丝。
- 五官强调较大的日漫眼睛、简化鼻口、清楚但不过度复杂的眉眼表情。
- 服装优先保证袖口、领口、下摆和鞋型在小尺寸下可辨认，而不是追求写实布料褶皱。

## 渲染与2D表现

- 使用 3 渲 2：Blender 负责权威模型、绑定、动画、灯光和多方向渲染。
- 优先使用柔和赛璐璐/软卡通明暗，控制为少量清晰色阶；避免照片级 PBR、强噪声和过细纹理。
- 轮廓应清楚，但线条不能在低分辨率下变成连续黑块。
- 颜色整体明快、偏幻想 JRPG；同一角色需要明确主色、辅色和小面积强调色。
- 先在 256px 渲染检查结构，再用 nearest-neighbour 生成本地像素审查版本；最终游戏分辨率由后续导出功能确认。
- 正、右、背、左以及动作循环必须保持同一比例、光照和摄像机合同。

## 旧 ImageGen 男女图的处理

旧 ImageGen 男女风格/步行图属于 2D 直生成阶段，其人物结构和当前 Actor 已有差距，且该生成路线已经停止。因此：

- 不把旧图恢复为正式模型、生成输入或验收模板；
- 不复制到当前仓库，继续保留在 AssetsLab 历史中；
- 其中“Q版比例、柔和线条、明快日漫感”的意图已转写为本文档；
- F001 能稳定显示当前 Actor 后，再从当前 Actor 生成新的正侧背美术基准图，经用户确认后进入 `references/art_direction/`。

## 验收问题

每个角色或主要资产晋级前至少回答：

1. 放在当前 Actor 上是否仍然像同一款 Q 版日漫 JRPG 游戏？
2. 在预期2D尺寸下，发型、脸、袖口、裤腿和鞋型是否可辨认？
3. 是否出现写实材质、过密细节或西式卡通比例偏移？
4. 正侧背和动作中是否保持同一角色身份与配色？
5. 是否借用了参考作品的具体独特设计，而不是只借鉴抽象风格？
6. 耳朵是否仍为独立可替换部件，并与头部、发型和头饰保持正确接缝、遮挡与绑定？

## 变更规则

美术方向变化必须记录日期、原因、受影响资产和迁移计划。新的视觉参考只有经过用户明确确认后才能替换当前基准。
