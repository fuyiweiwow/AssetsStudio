## 眼眉细节的分层合同

不是“生成完整角色 → 生成带五官的 3D → 抹平网格”。新路线区分三类图：

1. **风格确认图 A**：仅暂留大眼、简单眉毛，帮助稳定 Q 版动漫风格。光头、无耳、无鼻无嘴、无衣物配件；身体保持连续中性无性征玩具壳。眼眉例外仅适用于这个二维阶段，不能覆盖最终 Actor Core 的无五官约束。
2. **几何候选图 B**：从 A 局部编辑，去除眼、眉、眼线以及相关凹陷和阴影；以同材质连续曲面补全，不简单涂白，不整幅重生成。头顶、脸颊、下颌、后脑、颈部、身体、姿态、镜头、画布、照明均应保持。脸部变成球体、身形改变或补出鼻嘴时拒绝。
3. **后续角色表现层 C**：成品眼睛与眉毛优先作为独立贴图/表现层验证，不要求底层素体包含眼窝或其他身份几何。无鼻无嘴要求继续有效。

保留 A 与 B 两份原图、编辑提示词和来源哈希。A 用于美术对照，不默认送入图生 3D；B 只有通过局部编辑和形体检查后才有资格成为几何输入。单视图去除通过并不能证明侧面方向性或四向一致性通过。

### 已知失败对新方案的限制

- 直接无五官重建曾丢失侧头方向性；侧视必须通过浅面部平面、下颌与后脑体积分布表达朝向，而非靠鼻尖。
- 大眼与眉毛曾被三维模型编码成浅表起伏；不得把“只有贴图”当作图生 3D 的可靠假设。
- 网格抹脸曾残留波纹或造成额头/鼻部楔形变形；它不是默认兜底方案。
- Klein/Qwen 零样本去部件和旧 LoRA 实验有已记录失败；本轮只验证二维设计/局部编辑方法，不宣称已解决本地批量生产、训练或 RTX 3060 推理资格。

### 首轮实验：正面 A/B 对照

- 输入：已入库用户风格参考的真实像素；风格保持 Q 版日漫西幻柔和手办感，比例采用上述三头身实验假设。

- 核查：头身比例、宽弧头和下颌、窄身短肢、手腕和紧凑手足、无鼻无嘴、无服装状边界；再检查 A/B 身体轮廓、头部外轮廓与局部编辑区域外的像素漂移。
- 预设保形目标：相同画布、无独立缩放/平移配准；整个人物 silhouette IoU >= 0.98，bbox 边界漂移 <= 画布宽高的 0.5%。报告区域外 RGB MAE（0–255）、超过 8/255 的改动像素比例及头部局部轮廓，禁止用全图背景稀释人物误差。区域外人物 MAE > 3/255 或改动像素占比 > 5% 时标为需要复核/返修，而不是静默忽略。
- 五官是否清除、头型是否正确必须人工/视觉复核；自动像素分数不能替代。
- 首轮交付：A、B、对照/差异证据、提示词与检查报告。之后由用户评审造型和比例，再扩展同一素体的四向图。

## 不可变风格要求

以用户原始参考和选定 StyleProfile 为准，不以刚生成的网格反推美术标准。

- Q 版日漫西幻游戏手办感；柔和圆润的大块面、干净哑光、低至中等细节密度。
- 宽而弧形的动漫头，浅面部平面、收拢的下颌、有方向性的后脑；拒绝球头、平顶方头。
- 小而收束的躯干、短且清楚的四肢；拒绝写实成人解剖、长细肢体、梨形腹部和泛化婴儿模特。
- 素体必须光头、无耳、完全无五官、无眼窝；连续中性无性征表面。
- 不含衣服、发型、鞋靴、手套、饰品、袖口、鞋底、接缝或服装状结构。
- 短小连指手端与自然腕部过渡，无独立手指、无锤状掌球。紧凑圆足与小腿连续，不做靴状脚块。
- 成品角色可在后续独立层添加大眼和眉毛，但仍无嘴无鼻；不将这些特征烘进 Actor Core。

## 建议执行顺序

1. **正面二维造型评审**：按上述 A/B 合同，先用带眼眉候选评头、肩、躯干、四肢与手足的整体语言，再验证同图局部去五官能否保形。不做跨风格盲选。后续另给自然垂臂辅助图检查手端落点，不与 T Pose 几何源混用。
2. **同一素体四向定稿**：由选中的正面扩展 front/right/back/left 严格正交 T Pose，保留带眼风格对照和无脸几何输入两个版本。统一身高、中心线、头底、肩、胯、膝、腕与足底。保留一张斜俯视可读性图，但不把透视图当正交几何约束。不要四个方向各自独立发挥。
3. **冻结源资产**：记录图像哈希、StyleProfile、比例、人工确认与排除项。自动检查轮廓/对齐只是必要条件，不能代替整体风格和局部形状人工评审。不合格只改二维，暂不消耗三维和绑定工时。
4. **建立唯一基准素体**：复用本机现有环境与已有权重；图生 3D 可提供粗形体候选，不能直接认定为可动画成品。使用本机 Blender 完成参考对齐、肩胯肘膝的面流、连续封闭表面和最终形体检查。新下载仍优先 ModelScope，不为已具备的环境重复安装。
5. **绑定与游戏动作验证**：外观通过后选择一种绑定方式验证，避免同时混入自动骨架采样和新几何变量。检查垂臂、举臂、屈肘、抬腿，然后四向走跑、放置炸弹、转身与游戏俯视可读性。导出再导入，验证实际 GLB 变形，而非只看 Blender 渲染。
6. **扩展资产工作流**：基准素体同时通过美术与动作评审后才冻结骨架、比例和插槽，接入发型、服装、武器、配件与 Recipe。暂不训练新生成模型，也不扩展全自动多角色生产。

验收顺序不可颠倒：二维风格 → 多视图一致性 → 三维形体 → 拓扑/绑定 → 动作/导出 → 插槽组合。
