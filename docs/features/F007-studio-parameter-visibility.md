# F007 Studio 参数可见性复核

日期：2026-08-14

## 结论

本轮确认“数值变化但预览看不出”不是参数状态没有更新，而是两个预览条件叠加造成的：整套头发目标下发套可能被外层发束遮挡；前缘回缩改变的是前后中心，不会改变 Z 跨度。

Studio 试点现采用以下可复核方式：

- 识别 `HairSeed04ScalpBase`，保存原始 position buffer；
- 覆盖宽度围绕网格中心按 X 轴直接变形；
- 前缘回缩按 GLB 导出后的 -Z 深度轴移动；
- 报告命中网格数、X/Z 跨度和 Z 中心；
- “只看发套 + 单独展示”使用高对比检查材质，离开检查模式恢复原材质，不改变正式 Blender/GLB 材质；
- 当前目标不是发套时显示明确提示，避免把命中数为 0 误解为参数失效。

## Studio 验收记录

在 Conservative 发套候选上：

- `scalpWidth 0.94 → 1.10`：X 跨度增大，前视轮廓可见变宽；
- `frontRetraction 0 → 0.16`：Z 中心向后移动约 `0.16`，右侧视图可见前缘后移；
- 两项均命中 `1` 个真实发套网格；外层 `HairBundle_Female_Seed04` 未被修改。

## 边界

这仍是 Studio 预览试点，不回写 Blender 资产，也不自动把变形结果加入随机池。正式美术结论仍需在 Blender 四视图和 Walk 中确认；发套只负责填补组件间小裂缝，不替代刘海本身的贴合修复。
