# 功能：工作流作用域仓库与可折叠预览

- 功能 ID：`F005`
- 状态：`in_progress`
- 负责人：Codex 与用户共同审查
- 建立时间：2026-08-10
- 最近更新：2026-08-10
- 关联功能：F002、F003、F004

## 需求证据

用户指出资产仓库若始终显示全部类别，左侧工作流选择就失去意义；同时常驻 3D 预览占比过大，挤压仓库和参数控制台。用户进一步明确：工作流仓库只需为每个组件缓存一张固定角度预览，四视图不适合快速浏览。

## 范围

- 仓库数据严格跟随左侧当前工作流：模型/骨骼/动画映射到身体资产，发型、五官、上衣、裤子和鞋只显示各自类别。
- 每个组件在仓库只显示一张固定正面缓存图；四视图和 GIF 只用于进入预览后的审查。
- 每个工作流独立记住 3D 预览的显示/隐藏状态。
- 隐藏预览时同时隐藏相机、播放和放大控制，并把更多横向空间让给控制台。

## 非目标

- 不删除 Blender 四视图和 Walk GIF。
- 不把缩略图当作里程碑人工验收依据。
- 不在本轮增加同类别多资产选择或分页。

## 技术选型

| 问题 | 当前选择 | 原因 | 未选方案 |
| --- | --- | --- | --- |
| 仓库过滤 | 由 `WorkflowStepId` 确定唯一 `AssetCategory` | 规则可单元测试，避免组件内部自行猜测 | 在卡片层用 CSS 隐藏仍会让不可见资产参与交互 |
| 预览折叠 | 按工作流保存布尔状态 | 切换工作流后保留用户的空间偏好 | 单个全局开关无法表达“每个工作流” |
| 缩略图 | 从权威图确定性裁出固定正面图 | 一眼辨认且缓存很小 | 四视图 contact sheet 在小卡片中信息过密 |

## 验收条件

- [x] 单元测试确认结构工作流映射到 body，外观工作流只返回对应类别。
- [x] 浏览器确认切换左侧工作流时仓库只出现对应资产。
- [x] 浏览器确认隐藏/显示预览有效，且每个工作流分别记忆状态。
- [x] 上衣、裤子和鞋仓库卡片使用单张固定正面裁图，不显示四视图拼图。
- [ ] 用户确认信息密度和空间分配可继续使用。
