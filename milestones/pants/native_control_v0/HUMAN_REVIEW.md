## Reviewer checklist

Please judge the GIFs, not only the contact sheet:

| Item | Pass / Fail | Notes |
|---|---|---|
| Front coverage and crotch continuity | pending | |
| Side outer-thigh coverage | pending | |
| Back continuity and no tear | pending | |
| Garment remains outside the Actor | pending | |
| Face/expression remains visible | pending | |
| Bone-driven walk follows the Actor | pending | |

Automatic status is deliberately recorded as `fail_visual`; its old thresholds
are known to over-report this Actor-derived geometry, but it cannot be
overridden without the required human review. The repository Gallery links to
this provisional milestone and must not present it as `accepted`.
