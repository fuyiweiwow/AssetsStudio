# Recovered AssetsLab experiment archive

This directory is a documentation-and-tooling archive recovered from the related AssetsLab project. It preserves the goals, ActorProfile/Slot workflow, compiler scripts, manifests and historical audit conclusions that informed the Actor V2 restart.

The original milestone Blend, generated GLBs, master turnaround, calibration images and previews referenced by some files are not present in this checkout. Their paths and hashes are historical evidence only; do not treat this directory as a self-contained executable asset package.

The active AssetsStudio continuation is documented in `docs/workflows/actor_v2_image_first_rebuild.md`, with tracked visual sources under `references/actor_v2/`.
